# COVID-19 Data Visualization

A small project visualizing global COVID-19 data from [Our World in Data](https://ourworldindata.org/covid-cases).  
You can see global trends, top 10 countries, and select countries interactively.

## Features

- Global daily new cases line chart
- Top 10 countries total cases line chart
- Interactive country selection line chart

## Tech

Python, Pandas, Plotly, ipywidgets, Jupyter Notebook

## How to Run

1. Clone the repo:

   ```bash
   git clone https://github.com/your-username/covid_dashboard.git
   cd covid_dashboard
   ```

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Open `notebooks/analysis.ipynb` in Jupyter Notebook and run all cells.

## Data

From [Our World in Data](https://ourworldindata.org/covid-cases)
